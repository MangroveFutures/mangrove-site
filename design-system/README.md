# Design system

The Mangrove design system lives here.

## Files

- `index.html` — the living style guide: tokens, components, content model, copy guide, sketchbook, product template
- `tokens.css` — (coming) just the CSS custom properties, importable by any Mangrove surface

## How to use

Open `index.html` in a browser or via GitHub Pages at `/design-system/`. It is self-demonstrating — the components shown are the actual components from the site.

## How to update

1. Work on the artifact version first (the shareable Claude URL)
2. When a section is ready, copy into this file
3. Commit with a note on what changed and why (sketchbook principle — append, don't overwrite)

## Reuse for new products

See Section 07 of `index.html`. Copy the token layer, override `--accent` and `--bg`, inherit everything else.
