SketchIn

A findable record of every design, sketch and page you have made: each one given an ID, a snapshot, a written description and its links to the others.

In development. The pipeline runs over Mangrove's design catalogue of more than 1,300 designs, and its tests run on every change. Photographing a sketch and reading it with a vision model is the next stage and is not built yet.

Who it is for

Designers and studios with a large body of work they cannot see all at once. Today it is built for Mangrove's own design catalogue, and the same pipeline is meant to run on a client's material, kept on that client's own machine.

Open question. The old card said: photograph a sketch and get text. The repository is a design-catalogue pipeline. Which one is the product is Rosie's call. Review note, not page copy.

Design work scatters: a folder here, a chat there, a screenshot somewhere else. SketchIn gives each piece one permanent ID, records where the real file lives, takes a snapshot, writes a description, and links it to related work, so any piece can be found and cited later. It started as the idea of photographing a hand sketch and turning it into something digital, and that remains the aim for a later stage.

In detail

  1. Registers each design with a stable ID and a fingerprint of its contents. If the file changes, a new version is added and the old one is kept.

  2. Writes a description of every design and keeps a snapshot reference, either by plain rules run on your own machine or from text written by a person or an agent and imported.

  3. Finds things by meaning. A search for a phrase returns the design and where the original is stored. Embeddings are made locally, so nothing leaves the machine.

  4. Keeps client work private by design. Anything marked as client work is never described by an AI, and the database refuses it.

  5. Links each design into a graph with the parts of the design system it belongs to and the reactions people have had to it, so the question "what did we dislike about this" can be asked.
